## 年付比月付省多少：拿两个档位算一遍

这个问题不能只比单价，得算整年支出。

1GB 档：年付 $21.99，按月付 1GB 常规套餐 $17.99 计算，一年是 **$215.88**，差距接近 10 倍。
2GB 档：年付 $35.99，按月付 2GB 常规套餐 $20.59 计算，一年是 **$247.08**，差距约 6.9 倍。

这里有个容易误读的地方要说明白：常规月付套餐的配置其实更高。1GB 常规是 2 核 / 50 GB SSD / 1 TB 流量，而 1GB 特价是 1 核 / 20 GB SSD / 3 TB 流量。所以上面对比的不是同一台机器的两种买法，而是"同样是 1G 或 2G 内存，走哪条产品线更省钱"。

结论没变：只要你确定这台机器会用满一年，Specials 年付是唯一合理的选择。月付的价值在别的地方，短期试机房、需要特价没覆盖的机房、临时跑一两个月的项目。为了省十几美元而按月付用满一年，等于多花两百美元。

## 续费、取消、逾期：三条会真正影响你的规则

**续费同价是真的。** Specials 页面 FAQ 明确写着这些套餐属于 lifetime recurring，不取消就一直按购买时的价格续费。你今年 $21.99 买的 1GB，明年续费还是 $21.99。这条对低价 VPS 尤其重要，很多商家首年低价、续费翻几倍，锁价才是这类年付套餐的核心价值。

测法比测什么更重要：

1. 在自己电脑上 ping 测试 IP 至少 50 次，看平均延迟和丢包率。
2. 白天测一次，晚高峰 20:00–23:00 再测一次。只看白天数据会误判。
3. 用 `mtr`（Windows 用 `tracert`）看去程经过哪些节点、从哪一跳开始丢包。

5. 访客主要在美国或做外贸站，直接选离客户最近的机房，不用只盯美西。

## 下单和开机：五分钟能做完的事

下单流程：选套餐 → 选年付或两年付 → 选操作系统 → 选机房 → 填真实姓名、地址、常用邮箱 → 付款。结账页支持 PayPal、信用卡、Stripe 支付宝、银联卡、USDT/USDC、Boleto 和电汇，国内用户用支付宝最方便。没有微信支付。官方说明付款后立即开通，几分钟内收到含 IP 和 root 密码的邮件，也能在 ctrl 面板里查看。

开机后按顺序做这几件事：

1. 从本地 ping 新 IP，再测 22 端口通不通，有问题尽早开工单。
2. `passwd` 改掉初始 root 密码。
3. `apt update && apt upgrade -y` 更新系统。
4. 上传 SSH 公钥，在 `/etc/ssh/sshd_config` 关闭密码登录。
5. 用 `ufw` 只放行 22、80、443。ctrl 面板里的网络防火墙在流量到达服务器前就过滤，配错了还能用 VNC 控制台救回来。
6. 1GB 内存跑 WordPress，加 1–2 GB swap。
7. 定期把网站和数据库备份到别的地方，服务条款写明 RackNerd 不对数据完整性负责。

挖矿、发垃圾邮件、暴力破解、对外 DDoS 都是明确禁止的，违规直接停机。

## 常见问题

**续费会涨价吗？**
不会。Specials 的套餐是 lifetime recurring，按购买价续费，前提是不取消。

**可以退款吗？**
默认不退款，只能个案联系客服处理，账户余额不可退。这也是建议先想清楚再下单的原因。

**支持支付宝吗？**
支持。结账页有 Stripe 支付宝和银联卡，另有 PayPal、信用卡、USDT/USDC 等。

**1GB 够建站吗？**
静态站、轻量 WordPress、学习环境够用。跑 WordPress + MySQL 建议直接上 2GB，1GB 上数据库容易吃紧，还要靠 swap 撑。

**两年付划算吗？**
价格上没有任何优惠，两年付就是两个年付价相加。想省事可以买，想省钱没必要。

**有 VPS 优惠码吗？**
截至 2026 年 11 月，官网没有 VPS 通用优惠码，特价套餐本身就是促销价，网上流传的多为过期旧码。只有独立服务器有官网公布的 `15OFFDEDI`，终身减 15%。
